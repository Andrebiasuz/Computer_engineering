
# Sql — Learning & Projects

**Learning** lives under `learning/` and **real utilities** under `projects/`.

## Suggested Learning Path
- 01_basics → syntax, tooling
- 02_data_structures → lists/arrays, dicts/maps, structs/classes
- 03_io_networking → files, sockets; for automation: protocols and parsing
- 04_automation_examples → OPC UA, MQTT, Modbus, CSV logging
- exercises → small practice tasks

## Projects Folders
- plc_tools → helpers for PLC workflows
- scada_scripts → scripts usable in SCADA/HMI environments
- robot_programs → utilities for ABB/KUKA/Fanuc/UR
- data_logging → pipelines to CSV/SQLite/PostgreSQL
- utilities → misc helpers (converters, tag generators)
