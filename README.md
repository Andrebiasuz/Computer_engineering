
# Automation Programming Languages (Top-10)

This repository organizes **learning materials** and **small projects** for the current top-10 most used programming languages, adapted to **industrial automation** use cases (OPC UA, MQTT, SCADA scripting, PLC/robot utilities, and data logging).

## Structure
- `<language>/learning/` — tutorials, exercises, and notes
- `<language>/projects/` — real utilities and scripts (plc_tools, scada_scripts, robot_programs, data_logging, utilities)
- `<language>/templates/` — per-language boilerplate and examples
- `shared_templates/` — cross-language README/config/logging templates
- `references/` — cheat sheets and notes
- `tests/` — optional cross-language test rigs (OPC UA mock server, MQTT broker setup)

> Tip: Start with `python/` if you are new. It's beginner-friendly and widely used for automation tooling.
