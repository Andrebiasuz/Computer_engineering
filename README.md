This repository organizes **learning materials** and **small projects** 

## Projects

All of these are published at <https://andrebiasuz.github.io/Computer_engineering/>.

- [`scrum-board/`](scrum-board/): a sticky-note kanban board for several projects, with swimlanes and a weekly history ([live](https://andrebiasuz.github.io/Computer_engineering/scrum-board/))
- [`loop-planner/`](loop-planner/): draw an instrument loop by drag and drop and get reminded of everything to order per cable and item (glands, lugs, ferrules, markers...) ([live](https://andrebiasuz.github.io/Computer_engineering/loop-planner/))
- [`task-tracker/`](task-tracker/): a local, offline Trello-style task tracker ([live](https://andrebiasuz.github.io/Computer_engineering/task-tracker/))
- `study-tracker/` (on the `claude/study-tracker-app-paaho3` branch): a study tracker ([live](https://andrebiasuz.github.io/Computer_engineering/study-tracker/))
